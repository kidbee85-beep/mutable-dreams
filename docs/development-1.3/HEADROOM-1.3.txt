GOOD NEXT USES OF SPACE
- More genuinely different presets/Biomes using existing engines. Stored
  recipes add flash, not processing cost until selected. Preserve stable IDs.
- MIDI Learn, takeover, controller maps and improved synchronization: bounded
  control work, no new audio buffers. Measure bursts and save-format overhead.
- Sequence variations, mute/solo workflow and compact parameter locks.
- One further kit of the existing size would need about 32,000 PCM bytes plus
  definitions/code, leaving less room for MIDI/features. It looks plausible
  in flash, but is not implemented or automatically approved by these numbers.
- Lightweight tonal variants reusing existing state/filter/modulation paths.

NOT FREE CAPACITY
Long stereo samples, a second grain tape, convolution and unrestricted added
voices are poor fits for the current remaining pool. User WAV import needs a
separate safe storage, conversion and backup design. Bluetooth is deliberately
out of scope for this version. Do not remove quality guards to gain features.
