# Mutable Dreams 2.0 DAW monitoring

On the FM-1, press GLO until **USB AUDIO** appears. Turn K1 left to mute the
speaker and headphone output. Turn right to hear the FM-1 locally again.
The USB mix keeps the same gain, and MASTER sets its recording level. Hold
GLO for help. With transport stopped and the internal clock selected, SAVE
on this page writes preferences only.

The track channel on **MIDI / PERFORMANCE** selects the MIDI input for that
voice. A Logic Pro audio track records the audio input selected in its channel
strip. The standard FM-1 profile delivers the stereo mix to inputs 1 and 2.

## Eight-channel test profile

In a separate build copy, set `usb_audio_channels = 8` in `app/fm1.toml`.
The USB input device runs at 44.1 kHz. Use inputs 1 and 2 for the stereo mix
with shared effects. In Logic Pro, create six mono audio tracks and set their
inputs to 3 through 8 for voices 1 through 6. The mono stems follow the voice
level, mute and shaping and are taken before pan and shared effects. They run
at a fixed USB level. In kit mode the kit is on input 6 and inputs 7 and 8
carry silence.

This profile uses the existing fm1-base USB audio ring. Display tiles are
20 rows high to fund the ring while retaining 8 KiB of reserved DSP memory.
The native and browser stereo profiles continue using 30-row tiles.

## Startup click

The optional startup tone ramps out when an action dismisses it. The
digital output is initialized to silence. The codec and amplifier can
also produce a transient when power comes up or drops. Compare the
speaker and headphones on a real cold start with the startup sound off.
