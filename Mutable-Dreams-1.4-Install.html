Connect only the FM-1 you intend to update; disconnect other FM-1 units first. Install or update Mutable Dreams. Return to original M-VAVE V15 if needed.

Start from original FM-1 V15 or V16, or update from an earlier Mutable Dreams version using its matching backup workflow. On 1.0, stop and SAVE on the device, then follow the legacy backup steps in the guide; its live editor is not available yet. On 1.1 or later, back up saved User Banks as .mddb and export unsaved live edits as JSON before changing firmware. Returning to V15 erases User Banks and preferences. Official M-UPGRADE rejects this custom package: use this installer. Open the bank backup and editor. Read the complete guide.

Connect the FM-1 by USB, then press Install. It works in Chrome or Edge; the browser asks once to allow MIDI: allow it.

Do not unplug the USB cable while writing.
