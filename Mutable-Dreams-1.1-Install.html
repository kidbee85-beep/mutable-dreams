A new world,
one small instrument.

Install or update Mutable Dreams. Return to the original M-VAVE firmware whenever you choose.

Start from original FM-1 V15 or update directly from Mutable Dreams 1.0. On 1.0, stop and SAVE on the device, then follow the legacy backup steps in the guide; its live editor is not available yet. On 1.1, back up saved User Banks as .mddb and export unsaved live edits as JSON before changing firmware. Returning to V15 erases User Banks and preferences. Open the bank backup and editor. Read the complete guide.

Connect the FM-1 by USB, then press Install. It works in Chrome or Edge; the browser asks once to allow MIDI: allow it.

Do not unplug the USB cable while writing.
