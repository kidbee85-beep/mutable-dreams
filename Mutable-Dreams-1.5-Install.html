Connect only the FM-1 you intend to update; disconnect other FM-1 units first. Install or update Mutable Dreams. Return to original M-VAVE V15 if needed.

Start from original FM-1 V15 or V16, or update from an earlier Mutable Dreams version using its matching backup workflow. An older Mutable Dreams build on a UC25HQ80 unit may not enter update mode: return to official firmware first using the documented recovery path; do not force a stalled update. On 1.0, stop and SAVE on the device, then follow the legacy backup steps in the guide; its live editor is not available yet. On 1.1 or later, back up saved User Banks as .mddb and export unsaved live edits as JSON before changing firmware. Returning to V15 erases User Banks and preferences. Official M-UPGRADE rejects custom packages: use this installer. The revised updater returned USB MIDI automatically on the tested FM-1. If your FM-1 does not return after the write is complete, power it off, disconnect USB for five seconds, reconnect and press Verify. Open the bank backup and editor. Read the illustrated guide and full recovery notes.

Connect the FM-1 by USB, then press Install. It works in Chrome or Edge; the browser asks once to allow MIDI: allow it.

Do not unplug the USB cable while writing.
